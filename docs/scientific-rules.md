# Scientific and neutrality rules

1. Every policy object must retain a primary-source reference and source date/version.
2. Source text, interpretation, assumption, equation and output are separate fields.
3. The same parsing and simulation rules apply regardless of political origin.
4. Direct accounting effects may be deterministic when inputs are known.
5. Behavioral effects require a documented model, empirical estimate or explicit scenario.
6. Geopolitical and institutional uncertainty must not be converted into arbitrary point estimates.
7. Unknown information remains unknown; the engine emits a gap.
8. Time-dependent outputs carry an uncertainty class.
9. Interactions between policies must be represented before aggregating a whole programme.
10. Historical proposals must be labelled historical and never silently presented as current.
