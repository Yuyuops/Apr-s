# Module figurines (optionnel, désactivé par défaut)
**Règle : aucune figurine n'est inventée, générée ni conçue.** Le module recherche, identifie et propose des figurines LEGO existantes et référencées ; il ne fabrique aucun modèle 3D.
- `search.py THEME` : interroge le catalogue Rebrickable (instantané local `rb.db`) selon `themes/THEME.json` (règles de recherche, aucune figurine décrite) ; télécharge la photo du catalogue ; écrit `results/THEME_candidates.json` (nom exact, id catalogue, nb de pièces, photo, sets contenant la figurine, lien de page, disponibilité « non verifie », prix `null`, statut 3D « non intégré »). BrickLink (HTTP 405) et le site LEGO (403) ne sont pas consultables depuis cet environnement : aucune donnée n'en est reprise. Si rien n'est trouvé : « Aucune figurine verifiee ».
- `sheet.py THEME` : fiche de sélection (photos réelles) `results/THEME_selection.png`.
- `figures.py` : lit `figures.selected` (0 à 4 ids du catalogue ; tout id absent des résultats est rejeté), propose des emplacements (`shelf`, `frame`, `free_zone`) avec vérification des dimensions (emprise générique d'une minifigurine 2×2 tenons, non mesurée par référence) et des appuis ; `support_build: true` construit seulement une étagère VIDE en plaques ordinaires clipsées sur tenons (validable en LDraw). **L'intégration 3D de la figurine elle-même reste non validée** : aucun modèle LDraw exact n'est disponible dans ce dépôt.
- Configs : `figures_config_default.json` (off), `figures_config_example_italy.json`, `figures_config_example_hyrule.json`.
Résultats de recherche : voir `results/RECHERCHE_FIGURINES.md`.
